# كتل جاهزة — الصقها في UX Builder

هذه الكتل هي ما يصنع التميّز فعلاً. إعادة تلوين هيكل القالب لا تكفي:
العناوين الضخمة والأقواس والشريط المتحرك تحتاج **بنية** لتظهر فيها.

## كيف تلصق كتلة

1. حرّر الصفحة بـ **UX Builder**
2. أضف عنصر **Text** (أو **HTML** إن وُجد)
3. اضغط أيقونة **`< >`** (Source code / Text mode) — مهم جداً، وإلا تحوّل الوسوم إلى نص
4. الصق الكود
5. احفظ

> استبدل روابط الصور `#` بروابط صورك من مكتبة الوسائط.

---

## 1) الشريط المتحرك — أقوى عنصر تمييز بأقل جهد

ضعه أسفل الهيدر مباشرة. عنصر واحد يجعل الموقع يبدو مصنوعاً لا مركّباً.

```html
<div class="jn-marquee">
  <div class="jn-marquee__track">
    <span>Third-Party Tested</span><span>Non-GMO</span><span>No Fillers</span>
    <span>Free Shipping Over $50</span><span>Made in USA</span><span>Gluten Free</span>
    <span>Third-Party Tested</span><span>Non-GMO</span><span>No Fillers</span>
    <span>Free Shipping Over $50</span><span>Made in USA</span><span>Gluten Free</span>
  </div>
</div>
```

**مهم:** كرّر العناصر مرتين كما ترى — بذلك يبدو الشريط بلا نهاية.
للتحكم بالسرعة أضف `style="--jn-marquee-speed:50s"` على `jn-marquee`.
للون فاتح استخدم `jn-marquee jn-marquee--light`، وبلون علامتك `jn-marquee--accent`.

---

## 2) الهيرو — نصّ حيّ بدل نص مطبوع داخل صورة

**هذه أهم خطوة.** بانرك الحالي صورة JPG والعنوان مطبوع بداخلها، فلا يظهر التصميم
ولا يقرأه محرك البحث ولا يتكيّف مع الجوال.

```html
<div class="jn-hero jn-grain">
  <div>
    <span class="jn-eyebrow">Pure · Tested · Effective</span>
    <h1 class="jn-mega">Your health.<br>Our formula.</h1>
    <p class="jn-lead">Carefully selected supplements made with premium ingredients
    to support your health and wellness — naturally.</p>
    <div class="jn-hero__cta">
      <a class="button primary" href="/shop/">Shop all products</a>
      <a class="button is-outline" href="/about/">Why Jannatan</a>
    </div>
  </div>
  <div class="jn-arch"><img src="#" alt="Jannatan supplements"></div>
</div>
```

اقصص صورة منتجاتك بلا نص، وضعها في `src`. القوس سيتكفّل بالشكل.

---

## 3) بلاطات التصنيفات المقوّسة

بديل عن قائمة التصنيفات النصّية الحالية. القوس هو توقيع التصميم.

```html
<div class="jn-archgrid jn-offset">
  <a class="jn-archcard" href="/product-category/immune-support/">
    <span class="jn-arch"><img src="#" alt="Immune Support"></span>
    <span class="jn-archcard__name">Immune Support</span>
    <span class="jn-archcard__meta">6 products</span>
  </a>
  <a class="jn-archcard" href="/product-category/sleep/">
    <span class="jn-arch"><img src="#" alt="Sleep"></span>
    <span class="jn-archcard__name">Sleep</span>
    <span class="jn-archcard__meta">4 products</span>
  </a>
  <a class="jn-archcard" href="/product-category/heart-health/">
    <span class="jn-arch"><img src="#" alt="Heart Health"></span>
    <span class="jn-archcard__name">Heart Health</span>
    <span class="jn-archcard__meta">4 products</span>
  </a>
  <a class="jn-archcard" href="/product-category/gut-health/">
    <span class="jn-arch"><img src="#" alt="Gut Health"></span>
    <span class="jn-archcard__name">Gut Health</span>
    <span class="jn-archcard__meta">3 products</span>
  </a>
</div>
```

الكلاس `jn-offset` يُنزل البلاطات الزوجية قليلاً فتُكسر رتابة الصف المستقيم.
احذفه إن أردت صفاً مستوياً.

---

## 4) قسم تحريري — عنوان ضخم وصورة مقوّسة

ضع اثنين منه بالتناوب: الأول عادي، والثاني بكلاس `jn-editorial--flip`
لتنقلب الصورة إلى الجهة الأخرى.

```html
<div class="jn-editorial">
  <div>
    <span class="jn-eyebrow">Our promise</span>
    <h2>Tested, not just trusted.</h2>
    <p>Every batch goes to an independent lab before it reaches you. We publish the
    certificate on each product page — so you never have to take our word for it.</p>
    <a class="jn-more" href="/about/">Read our standards</a>
  </div>
  <div class="jn-arch"><img src="#" alt="Lab testing"></div>
</div>
```

النسخة المقلوبة:

```html
<div class="jn-editorial jn-editorial--flip">
  <div class="jn-arch"><img src="#" alt="Ingredients"></div>
  <div>
    <span class="jn-eyebrow">What's inside</span>
    <h2>No fillers. Ever.</h2>
    <p>No artificial colors, no unnecessary binders, no proprietary blends that hide
    the real dose. The label is the whole story.</p>
    <a class="jn-more" href="/shop/">Browse the range</a>
  </div>
</div>
```

## 5) الخطوات المرقّمة

الأرقام مفرّغة (خط خارجي فقط) — تعطي حضوراً بلا ثِقل.
استخدمها **فقط** حين يكون هناك تسلسل حقيقي.

```html
<div class="jn-steps">
  <div class="jn-step">
    <span class="jn-step__n">01</span>
    <h3>Pick your goal</h3>
    <p>Sleep, immunity, joints — browse by what you actually want to improve.</p>
  </div>
  <div class="jn-step">
    <span class="jn-step__n">02</span>
    <h3>Check the label</h3>
    <p>Full ingredient list and lab certificate on every product page.</p>
  </div>
  <div class="jn-step">
    <span class="jn-step__n">03</span>
    <h3>Get it in 24h</h3>
    <p>Shipped from New York, tracked to your door.</p>
  </div>
</div>
```

---

## 6) اقتباس ضخم من عميل

ضعه في قسم بخلفية بيج (`jn-tile-bg`) بحشوة واسعة.

```html
<div>
  <span class="jn-stars">★★★★★</span>
  <blockquote class="jn-quote">
    The only brand my whole family actually takes.
    <span class="jn-quote__by">Rosen P. · Verified buyer</span>
  </blockquote>
</div>
```

> لا تضع مراجعات مُختلقة. فعّل مراجعات ووكومرس واطلبها بعد الشراء أولاً.

---

## 7) علامة الفوتر الضخمة

ضعها آخر عنصر قبل الفوتر. الاسم مقصوص عند الحافة — تفصيلة تُشعر بأن الموقع مصمَّم.

```html
<div class="jn-wordmark"><span>JANNATAN</span></div>
```

---

## 8) شريط الادعاءات الثابت (بديل الشريط المتحرك)

```html
<div class="jn-claims">
  <span>Third-Party Tested</span>
  <span>Non-GMO</span>
  <span>Gluten Free</span>
  <span>No Fillers</span>
  <span>Made in USA</span>
</div>
```

## الترتيب المقترح للصفحة الرئيسية

```
الهيدر
1. الشريط المتحرك              ← jn-marquee
2. الهيرو                       ← jn-hero  (خلفية بيضاء)
3. بلاطات التصنيفات             ← jn-archgrid  (قسم بيج jn-tile-bg)
4. الأكثر مبيعاً                ← عنصر Products من Flatsome + كلاس jn-pcards
5. قسم تحريري «Tested»          ← jn-editorial  (أبيض)
6. قسم تحريري «No fillers»      ← jn-editorial--flip  (بيج)
7. الخطوات الثلاث               ← jn-steps  (أبيض)
8. الاقتباس                     ← jn-quote  (بيج)
9. وصلات جديدة                  ← Products + jn-pcards
10. علامة الفوتر الضخمة          ← jn-wordmark
الفوتر
```

**قاعدة الإيقاع:** بادل بين الأبيض والبيج. القسمان المتتاليان بنفس الخلفية يذوبان في بعضهما.

---

## كلاس `jn-pcards` لشبكة المنتجات

ضعه في خانة **Class Name** لعنصر **Products** في UX Builder.
يحوّل صور المنتجات إلى أقواس، ويُظهر زر الإضافة انزلاقاً عند المرور على الديسكتوب.

## لماذا لم يكن التصميم مميّزاً قبل هذه الكتل

| السبب | العلاج |
|-------|--------|
| العنوان مطبوع داخل صورة البانر | الكتلة رقم **2** — نص حيّ |
| لا توجد أقسام تحريرية إطلاقاً | الكتل **4** و**5** و**6** |
| التصنيفات قائمة نصّية بلا صور | الكتلة **3** |
| لا يوجد أي عنصر حركة | الكتلة **1** |
| صفحة تنتهي فجأة عند الفوتر | الكتلة **7** |
| 9 منتجات بلا صورة | لا يعالجه تصميم — انظر `05-اصلاحات-المحتوى.md` |
