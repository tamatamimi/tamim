## ما الذي يجعل ذلك الموقع مميّزاً (وما نقلناه)

| العنصر | عندهم | عندنا |
|--------|-------|-------|
| **العناوين** | خط مضغوط عريض جداً، حتى `96px` على الديسكتوب، تباعد أسطر `115%`، تتبّع `-0.025em` | خط `Archivo` بعرض مضغوط `78%` ووزن `800`، سلم من `44px` إلى `96px` يتضخم تلقائياً |
| **النصوص** | Poppins — `16px` بتباعد `150%` | Poppins نفسه |
| **الاستدارة** | `8px` فقط للأزرار والحقول، و`24px` للحاويات (`1rem + 8px`) | نفس المنطق: متغيّر واحد `--jn-r: 8px` وكل شيء مشتق منه |
| **الحدود** | `--border-width: 0` — لا حدود ولا ظلال إطلاقاً | البطاقات بلا حد ولا ظل؛ الفصل بكتل لونية فقط |
| **الأزرار** | ارتفاع `48px`، خط `14px` وزن `700`، `gap: 1ch` | مطابق |
| **الروابط** | تسطير بمسافة `4px` تصبح `6px` عند المرور | مطابق |
| **الإيقاع** | حشوة أقسام `2rem` جوال ← `3rem` لوحي ← `4rem` ديسكتوب | مطابق |

**الفكرة الجوهرية:** التميّز لا يأتي من الزخرفة، بل من **التباين الحاد بين عنوان ضخم جداً ونص صغير هادئ**، ومن **المساحة الفارغة**، ومن **غياب الحدود والظلال تماماً**.

## طريقتان للتركيب

### الطريقة الأولى — لصق مباشر (الأسرع)

1. افتح `flatsome-child/assets/css/jannatan-modern.css`
2. انسخ **كل** محتواه
3. الصقه في: **المظهر ← تخصيص ← CSS إضافي**
4. احفظ

> **مهم:** سطر `@import` الخاص بالخطوط يجب أن يبقى في **أول** الملف تماماً، وإلا تجاهله المتصفح.
> وقبل اللصق، احذف كتلة الـ CSS القديمة التي تفرض `max-width: 100% !important` (تفاصيلها في `02-التنصيب.md`).

### الطريقة الثانية — القالب الابن (الأفضل)

ارفع مجلد `flatsome-child` كقالب ابن. الملف يُحمَّل تلقائياً مع تحسينات WooCommerce الإضافية
(شارات ثقة، شريط شراء ثابت، شريط تنقل سفلي، مؤشّر شحن مجاني). الخطوات في `02-التنصيب.md`.

## الألوان: لا تعدّلها من هذا الملف

الملف **يرث ألوان قالبك تلقائياً**:

```css
--jn-accent: var(--fs-color-primary, #079616);
```

أي أن تغيير اللون الأساسي من **Flatsome ← Theme Options ← Style ← Colors** يغيّر كل الأزرار
والروابط والشارات فوراً. لا حاجة للمس ملف الـ CSS.

المتغيّرات الوحيدة التي قد تودّ تعديلها موجودة في القسم `00` أعلى الملف:

```css
--jn-ink:    #191919;   /* لون النص — رمادي داكن أفضل من الأسود الصريح */
--jn-tile:   #F4F1EC;   /* الكتلة البيج التي تجلس عليها صور المنتجات */
--jn-r:      8px;       /* الاستدارة — كل شيء آخر مشتق منها */
--jn-wdth:   78;        /* درجة ضغط العناوين: 62.5 شديد · 100 عادي */
--jn-max:    1320px;    /* عرض الموقع */
```

**جرّب `--jn-wdth`:** خفّضه إلى `65` لعناوين أكثر حدّة ودراما، أو ارفعه إلى `90` لمظهر أهدأ.
هذا المتغيّر وحده يغيّر شخصية الموقع بالكامل.

## كلاسات جاهزة لـ UX Builder

ضع أياً منها في خانة **Class Name** لأي عنصر داخل UX Builder:

| الكلاس | ما يفعله |
|--------|----------|
| `jn-mega` | يحوّل أي عنوان إلى عنوان هيرو ضخم (حتى 96px) بتباعد أسطر مضغوط |
| `jn-eyebrow` | سطر صغير بأحرف كبيرة فوق العنوان (مثل `NEW ARRIVALS`) |
| `jn-lead` | نص تمهيدي أكبر تحت العنوان، بعرض قراءة مريح |
| `jn-tile-bg` | خلفية بيج للقسم — استخدمها بالتناوب مع الأبيض |
| `jn-ink-bg` | قسم داكن كامل بنص أبيض |
| `jn-accent-bg` | قسم بلون علامتك التجارية |
| `jn-claims` | شريط الادعاءات: `Whole Grains · Plant Based · Nut Free` |
| `jn-hero` | كتلة هيرو جاهزة: نص + صورة داخل مربّع بيج مستدير |
| `jn-cats` / `jn-cat` | شبكة بطاقات التصنيفات بنسبة 4:5 |
| `jn-more` | رابط «المزيد» بسهم يتحرّك عند المرور |
| `jn-round` | استدارة 24px لأي عنصر (صورة، بانر، عمود) |
| `jn-media-4-5` · `jn-media-16-9` · `jn-media-1-1` | نسبة صورة ثابتة + قص تلقائي + استدارة |
| `jn-grid-3` / `jn-grid-2` | شبكة جاهزة تنهار إلى عمود واحد على الجوال |
| `jn-narrow` / `jn-wide` | يضغط أو يوسّع العناوين داخل هذا العنصر فقط |
| `jn-reveal` | ظهور تدريجي للقسم عند التمرير |

### مثال: شريط الادعاءات

الصق هذا في عنصر **HTML** داخل UX Builder:

```html
<div class="jn-claims">
  <span>Third-Party Tested</span>
  <span>Non-GMO</span>
  <span>Gluten Free</span>
  <span>No Fillers</span>
  <span>Made in USA</span>
</div>
```

### مثال: كتلة هيرو

```html
<div class="jn-hero">
  <div>
    <span class="jn-eyebrow">Pure · Tested · Effective</span>
    <h1 class="jn-mega">Supplements your body actually recognizes</h1>
    <p class="jn-lead">Clean formulas, third-party tested, made from ingredients you can pronounce.</p>
    <div class="jn-hero__cta">
      <a class="button primary" href="/shop/">Shop all products</a>
      <a class="button is-outline" href="/about/">Our story</a>
    </div>
  </div>
  <div class="jn-hero__media"><img src="رابط-الصورة.jpg" alt="Jannatan supplements"></div>
</div>
```

## قواعد لا تكسرها

هذه اللغة تنهار إذا خُلطت مع عادات القوالب الجاهزة:

1. **لا تضف ظلالاً للبطاقات.** الفصل يتم بالكتل اللونية، لا بالظل.
2. **لا تضف حدوداً حول كل شيء.** الحدّ الوحيد المسموح هو الخط الشعري `--jn-hairline` بين الصفوف.
3. **لا تجعل الأزرار بيضاوية كاملة (pill).** الاستدارة `8px` هي التوقيع.
4. **لا تصغّر العناوين.** العنوان الضخم هو مصدر التميّز كله — إن صغّرته صار الموقع عادياً.
5. **لا تستخدم أكثر من لونين للأفعال.** لون العلامة للزر الأساسي، والأسود للزر الثانوي.
6. **اترك مساحة فارغة.** الحشوة `4rem` بين الأقسام ليست إسرافاً، بل هي التصميم نفسه.

## ملاحظة عن الخطوط

- **Archivo** خط متغيّر مجاني من Google Fonts يدعم محور العرض (`wdth`)، وهو أقرب بديل مجاني
  لخط `Henriette Compressed` التجاري المستخدم في naturesbakery.
- الملف يضبط `font-stretch` و`font-variation-settings` معاً، فيعمل مع النسخة المتغيّرة والنسخ الثابتة.
- **للأداء الأفضل:** حمّل الخطين محلياً عبر إضافة *OMGF*، ثم احذف سطر `@import` من أول الملف.
- **عند إضافة العربية:** القسم `16` يبدّل الخط تلقائياً إلى `IBM Plex Sans Arabic` ويلغي الضغط
  والتتبّع السالب (لأنهما يضرّان بقراءة العربية).

## تبديل الخط إلى Tajawal

Tajawal خط مجاني من Google Fonts يدعم **العربية والإنجليزية معاً** بأوزان من 400 إلى 900.

### كيف

في القسم `00` من ملف `jannatan-modern.css` ستجد كتلة جاهزة. احذف علامتَي التعليق حولها فقط:

```css
/* قبل */
/*
--jn-display:     "Tajawal", "Poppins", sans-serif;
--jn-body:        "Tajawal", "Poppins", sans-serif;
--jn-wdth:        100;
--jn-head-weight: 900;
--jn-head-track:  -.02em;
*/

/* بعد */
--jn-display:     "Tajawal", "Poppins", sans-serif;
--jn-body:        "Tajawal", "Poppins", sans-serif;
--jn-wdth:        100;
--jn-head-weight: 900;
--jn-head-track:  -.02em;
```

هذا كل شيء. سطر `@import` في أعلى الملف يحمّل Tajawal أصلاً، والمتصفح لا ينزّل ملفات الخط
إلا عند استخدامه فعلياً — فلا تكلفة أداء إن بقيت الكتلة معلّقة.

### المقايضة التي يجب أن تعرفها

**Tajawal ليس خطاً مضغوطاً (Condensed).** والعناوين الضخمة المضغوطة هي مصدر التميّز البصري
في هذا التصميم، فبالتبديل ستفقد جزءاً من حدّتها.

ما يعوّض ذلك (مطبَّق في الكتلة أعلاه):

| التعويض | القيمة | السبب |
|---------|--------|-------|
| وزن أثقل | `900` بدل `800` | يستعيد الكثافة البصرية المفقودة |
| تتبّع أضيق | `-.02em` | يقارب الحروف فيبدو العنوان ككتلة واحدة |
| العنوان أكبر قليلاً | ارفع `--jn-fs-xl` إلى `clamp(3rem, 7.5vw, 6.5rem)` | الخط غير المضغوط يحتاج حجماً أكبر ليصل نفس الحضور |

### الخيار الأفضل: خط لكل لغة

إن كان متجرك بالإنجليزية اليوم وتخطّط للعربية لاحقاً، **لا تبدّل شيئاً**.
الملف يفعل هذا تلقائياً في القسم `16`:

- الإنجليزية → `Archivo` مضغوط للعناوين + `Poppins` للنصوص
- العربية → `Tajawal` بوزن 900، مع إلغاء الضغط والتتبّع السالب

**لماذا يُلغى التتبّع السالب في العربية:** الحروف العربية متصلة، والتتبّع السالب يشوّه
مواضع الاتصال ويجعل الكلمة أصعب قراءة. كذلك تباعد الأسطر يُرفع إلى `1.25` لأن الحروف العربية
لها امتدادات علوية وسفلية تحتاج مساحة أكثر من اللاتينية.

### بدائل عربية أخرى إن أردت تجربتها

| الخط | الطابع | يناسب |
|------|--------|-------|
| **Tajawal** | هندسي نظيف، أوزان حتى 900 | الأقرب لروح هذا التصميم — الخيار الموصى به |
| **IBM Plex Sans Arabic** | محايد تقني، قراءة ممتازة للنصوص الطويلة | متجر بمحتوى كثير |
| **Almarai** | بسيط ودّي | متاجر يومية |
| **Cairo** | شائع جداً | لكنه مستهلَك بصرياً — يقلّل الشعور بالتميّز |
| **Noto Kufi Arabic** | كوفي حديث بحضور قوي | العناوين فقط، لا النصوص |

لتجربة أي منها: بدّل كلمة `Tajawal` في الكتلة أعلاه، وأضف اسمه إلى سطر `@import` في أول الملف.
