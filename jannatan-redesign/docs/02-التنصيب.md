# التنصيب — خطوة بخطوة

الوقت المتوقع: **15 دقيقة**. لا يحتاج مبرمجاً.

---

## قبل أي شيء: نسخة احتياطية

من لوحة التحكم، خذ نسخة كاملة (ملفات + قاعدة بيانات) عبر UpdraftPlus أو من لوحة الاستضافة.
هذه ليست خطوة اختيارية.

---

## الخطوة 1 — تجهيز ملف القالب الابن

من مجلد `jannatan-redesign/flatsome-child/` أنشئ ملف ZIP اسمه `flatsome-child.zip` بحيث تكون بنيته:

```
flatsome-child/
├── style.css
├── functions.php
└── assets/
    ├── css/jannatan-modern.css
    └── js/jannatan-ui.js
```

> مهم: يجب أن يكون المجلد `flatsome-child` هو الجذر داخل الملف المضغوط، لا ملفاته مباشرة.

على ويندوز: انقر بزر يمين على مجلد `flatsome-child` ← إرسال إلى ← مجلد مضغوط.

---

## الخطوة 2 — الرفع والتفعيل

1. لوحة التحكم ← **المظهر (Appearance) ← القوالب (Themes) ← أضف جديد ← ارفع قالباً**
2. اختر `flatsome-child.zip` ← **التنصيب الآن**
3. **لا تفعّله بعد.** اقرأ الخطوة 3 أولاً.

### قبل التفعيل — انقل إعداداتك الحالية

عند التبديل إلى قالب ابن، قد تحتاج إعادة ضبط:

- **القوائم (Menus):** المظهر ← القوائم ← تبويب «إدارة المواقع» ← أعد تعيين القائمة لمكانها
- **الودجات (Widgets):** عادة تبقى كما هي، تحقق منها
- **إعدادات Flatsome:** محفوظة في قاعدة البيانات وتنتقل تلقائياً
- **صفحات UX Builder:** محفوظة داخل المقالات/الصفحات وتنتقل تلقائياً

خذ لقطات شاشة لإعدادات Flatsome ← Header قبل التبديل، للأمان.

الآن فعّل القالب الابن.

## الخطوة 3 — تنظيف الـ CSS القديم (ضروري جداً)

هذه الخطوة هي التي تُصلح مشكلة «المحتوى ملاصق للحواف».

اذهب إلى **المظهر ← تخصيص (Customize) ← CSS إضافي / Additional CSS** واحذف هذه الكتلة بالكامل:

```css
/* ── Full Width: Container & Row ── */
.container,
.row,
.main-container,
.page-wrapper {
  max-width: 100% !important;
  width: 100% !important;
  padding-left: 0 !important;
  padding-right: 0 !important;
}
```

سببها أنها تُلغي كل نظام الهوامش في القالب. الحزمة الجديدة تضبط العرض بشكل صحيح.

## الخطوة 6 — تفريغ الكاش

بعد الانتهاء:

1. أفرغ كاش إضافة التخزين المؤقت لديك (WP Rocket / LiteSpeed / W3TC)
2. أفرغ كاش Cloudflare إن وُجد
3. **مهم:** SuperPWA يخزّن نسخة من الموقع في متصفح الزائر — من إعداداته اضغط على زيادة رقم إصدار الـ Service Worker حتى يستلم الزوار النسخة الجديدة
4. افتح الموقع في نافذة تصفح خفي للتأكد

## ملاحظات تقنية

- **الخطوط:** الحزمة تحمّل Archivo + Poppins من Google Fonts. للأداء الأفضل ولتوافق GDPR، حمّلها محلياً عبر إضافة *OMGF* ثم احذف سطر `wp_enqueue_style('jannatan-fonts', …)` من `functions.php` وسطر `@import` من أول ملف الـ CSS.
- **الشحن المجاني:** قيمة الحد الافتراضية `50`. لتغييرها أضف في `functions.php`:
  ```php
  add_filter( 'jannatan_free_shipping_threshold', function () { return 75; } );
  ```
- **شارات الثقة:** عدّل نصوصها في الدالة `jannatan_pdp_trust_badges` داخل `functions.php`، ولا تكتب ادعاءات غير صحيحة (خصوصاً في فئة المكمّلات، حيث للـ FDA/FTC قواعد صارمة).
