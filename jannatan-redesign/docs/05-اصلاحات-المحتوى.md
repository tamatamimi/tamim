### 2) أضف صور المنتجات

نفس التسعة تعرض صورة `woocommerce-placeholder.webp`.

المواصفات المطلوبة:
- مقاس `1200×1200px`، مربّعة
- خلفية بيضاء موحّدة لكل المنتجات
- صيغة WebP، أقل من 150KB
- 3 صور لكل منتج: العبوة من الأمام / لقطة نمط حياة / ملصق الحقائق الغذائية

### 3) اكتب وصفاً لكل منتج

وصف Coq10 الحالي هو `---------` حرفياً.

قالب الوصف المقترح لكل منتج:
```
وصف قصير (سطران):  ما الذي يفعله ولمن
الفوائد:            3 نقاط
المكوّنات:          القائمة الكاملة + الجرعة لكل حصة
طريقة الاستخدام:    كبسولة واحدة يومياً مع الطعام
عدد الحصص:          60 كبسولة / 60 يوم
تحذير:              استشر طبيبك إن كنتِ حاملاً أو تتناول أدوية
```

### 4) صحّح تنسيق السعر
WooCommerce ← الإعدادات ← عام ← **Currency position** = `Left` ← لتظهر `$20.00` بدل `20.00 $`.
