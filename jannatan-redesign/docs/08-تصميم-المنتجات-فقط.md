# تصميم المنتجات فقط — بلا مساس بالقالب

ملف `flatsome-child/assets/css/jannatan-products.css` يعيد تصميم **المنتجات وطريقة عرضها فقط**،
ويترك كل شيء آخر على تصميم Flatsome الافتراضي.

## ما يلمسه

- **بطاقة المنتج** في المتجر والتصنيفات وذات الصلة: حدّ خفيف، استدارة، ظلّ عند المرور
- **صورة المنتج**: نسبة 1:1 ثابتة على خلفية فاتحة جداً، فتتساوى كل البطاقات مهما اختلفت الصور
- **الاسم**: سطران بارتفاع موحّد
- **السعر والتقييم**: تنسيق أوضح
- **زر الإضافة**: يملأ عرض البطاقة ويُدفع لأسفلها فتتساوى الصفوف
- **"Read more"** (منتج بلا سعر): يظهر كزر ثانوي لا كزر شراء
- **الشارات والمفضلة والعرض السريع**: أشكال أنظف
- **عمودان على الجوال** بدل عمود واحد
- **صفحة المنتج**: الصورة، السعر، حالة المخزون، الخيارات، عدّاد الكمية، زر الإضافة، التبويبات
- **ترقيم صفحات المتجر**

## ما لا يلمسه إطلاقاً

عرض الموقع · الهيدر · شريط البحث · القائمة · الفوتر · الخطوط العامة ·
الألوان الرئيسية · أي إعداد في Theme Options · أي صفحة غير المتجر والمنتج.

كل قاعدة مقيّدة بحاوية منتج (`.product-small` أو `.products .product` أو
`.single-product` أو `.woocommerce-pagination`)، فمن المستحيل أن تتسرّب لأي مكان آخر.

## التركيب

1. المظهر ← تخصيص ← **CSS إضافي**
2. الصق محتوى `jannatan-products.css` كاملاً
3. احفظ ثم أفرغ الكاش (LiteSpeed + SuperPWA)

لا يحتاج خطوطاً خارجية ولا `@import`. يرث لون علامتك تلقائياً عبر
`var(--fs-color-primary)`، فإن غيّرت اللون الأساسي من القالب تغيّر معه.

## تخصيص سريع (أعلى الملف، قسم 00)

```css
--jp-accent: var(--fs-color-primary, #079616);  /* لون الأزرار والأسعار المخفّضة */
--jp-tile:   #f6f6f4;   /* خلفية صورة المنتج — اجعلها #fff لإلغائها */
--jp-r:      12px;      /* استدارة البطاقة */
```
