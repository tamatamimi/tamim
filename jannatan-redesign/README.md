# إعادة تصميم واجهة jannatan.com

حزمة إعادة تصميم UI/UX لمتجر **Jannatan Naturals** (WordPress + Flatsome 3.20.9 + WooCommerce).

## المحتويات

```
jannatan-redesign/
├── flatsome-child/          ← قالب ابن جاهز للرفع (اضغطه ZIP وارفعه)
│   ├── style.css
│   ├── functions.php        ← تحسينات WooCommerce عبر hooks فقط
│   └── assets/
│       ├── css/jannatan-modern.css ← ملف التصميم الكامل (~900 سطر) — الصقه وحده أو ارفع القالب
│       └── js/jannatan-ui.js       ← شريط شراء ثابت، عدّاد كمية، بحث الجوال
├── docs/
│   ├── 01-التقرير-والتشخيص.md    ← تدقيق الموقع الحالي بالأدلة
│   ├── 02-التنصيب.md             ← 6 خطوات، 15 دقيقة
│   ├── 03-إعدادات-Flatsome.md    ← قيم دقيقة لكل حقل في Theme Options
│   ├── 04-بناء-الصفحة-الرئيسية.md ← مخطط الأقسام في UX Builder
│   ├── 05-اصلاحات-المحتوى.md      ← ما لا يحلّه التصميم (أسعار، صور، أوصاف)
│   ├── 06-اللغة-التصميمية.md      ← اللغة البصرية والكلاسات الجاهزة
│   ├── 07-كتل-جاهزة.md            ← ثماني كتل HTML تُلصق في UX Builder
│   └── 08-تصميم-المنتجات-فقط.md    ← ملف مخصّص للمنتجات لا يمسّ القالب
└── preview/
    ├── index.html            ← معاينة الصفحات كاملة
    └── sections-kit.html     ← معاينة حيّة للكتل الثماني
```

## ابدأ من هنا

1. اقرأ `docs/01` لتعرف ما المشكلة بالضبط
2. **للتطبيق السريع:** انسخ `flatsome-child/assets/css/jannatan-modern.css` كاملاً والصقه في
   المظهر ← تخصيص ← CSS إضافي. **للتطبيق الكامل:** طبّق `docs/02` ثم `docs/03`
3. **الأهم للتميّز:** الصق كتل `docs/07` في UX Builder — الـ CSS وحده يعيد تلوين
   هيكل موجود، والكتل هي ما يصنع الشكل
3. أعد بناء الصفحة الرئيسية حسب `docs/04`
4. **الأهم:** نفّذ قائمة `docs/05` — 9 من 12 منتج بلا سعر ولا صورة

## مبادئ التصميم المتّبعة

اللغة البصرية مستوحاة من **naturesbakery.com** (بألوانك أنت) — التفاصيل في `docs/06`.

| المبدأ | التطبيق |
|--------|---------|
| **عناوين ضخمة مضغوطة** | خط Archivo بعرض 78% ووزن 800، من 44px إلى 96px — هذا هو مصدر التميّز |
| **صفر حدود وصفر ظلال** | الفصل بكتل لونية بيج، لا بخطوط أو ظلال |
| **استدارة واحدة** | `--jn-r: 8px` وكل شيء آخر مشتق منها (`24px` للحاويات) |
| **الألوان موروثة** | `--jn-accent: var(--fs-color-primary)` — غيّر اللون من Flatsome لا من الملف |
| **هدف لمس 48px** | كل زر وحقل ومربع اختيار |
| **الجوال أولاً** | عمودان للمنتجات، شريط تنقل سفلي، شريط شراء ثابت |
| **حركة محترمة** | كل الانتقالات تتوقف مع `prefers-reduced-motion` |
| **جاهز للعربية** | متغيّرات منطقية (`inset-inline`) ودعم RTL يبدّل الخط تلقائياً |

## ما لا تفعله هذه الحزمة

- لا تعدّل أي ملف داخل قالب Flatsome الأصلي (آمنة مع التحديثات)
- لا تلمس قاعدة البيانات
- لا تضيف أسعاراً أو صوراً — هذا عمل يدوي، قائمته في `docs/05`

للتراجع: فعّل قالب Flatsome الأصلي من المظهر ← القوالب.
