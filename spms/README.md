# SPMS — نظام إدارة التخطيط الاستراتيجي

جامعة العلوم والتكنولوجيا - عدن | إدارة تقنية المعلومات

بناء على وثيقة `SPMS_Technical_Spec_for_Claude_Code` (Oracle Database + Oracle APEX)،
يُنفَّذ البناء على مراحل (P1–P9) كما هو محدد في القسم 9 من الوثيقة. كل مرحلة تُراجَع
قبل الانتقال للتي تليها.

## P1 — قاعدة البيانات

`sql/P1_schema.sql` ينشئ جداول القسم 3 من الوثيقة الفنية بالكامل:

- **الهيكل والمستخدمون**: `org_units` (شجرة هرمية)، `users`، ونموذج RBAC مرن
  (`roles` → `user_roles` → ... ← `role_permissions` ← `permissions`).
- **الخطة الاستراتيجية** (AD-01 — تأريخ فعّال بالإصدارات): `strategic_plans`،
  `dimensions`، `strategic_objectives`، `sub_objectives`، `kpis`،
  `kpi_yearly_targets` (REQ-030 — توزيع يدوي، لا آلي)، `projects`، `activities`
  (REQ-005 — نقطة إدخال واحدة)، `supporting_units`.
- **الخطط التشغيلية** (REQ-020..022 — اشتقاق موروث): `operational_plans`،
  `op_plan_items`.
- **الإنجاز والتدقيق**: `achievements`، `audit_log` (REQ-054)، `ui_labels`
  (REQ-060 — تعريب).

قرارات معمارية مطبّقة مباشرة في الـ DDL:

- **AD-01** (التأريخ الفعّال): `version_no`/`effective_from` على `strategic_plans`؛
  `strategic_plan_version` مثبّتة على `operational_plans` وقت الاشتقاق؛
  `report_snapshot_version` على `achievements`.
- **AD-02** (الأوزان الاختيارية): `weight_pct` قابل للـ NULL + `is_weight_explicit`
  على `dimensions`/`strategic_objectives`/`kpis`، مع قيد CHECK يفرض وجود `weight_pct`
  عندما `is_weight_explicit = 1`.
- **AD-05** (الترميز والاتجاه): كل الأسماء إنجليزية؛ الترميز AL32UTF8 يُضبط عند
  إنشاء قاعدة البيانات (خارج نطاق هذا السكربت).
- **AD-06** (Soft-delete): كل جدول جوهري يحمل `is_active` + `deleted_at` — لا حذف
  فيزيائي.

لم يُنفَّذ أي منطق أعمال في هذه المرحلة (لا حزم PL/SQL، لا triggers إجرائية) —
الجداول والقيود والفهارس فقط، حسب نطاق Prompt P1.

## المرجعية

- `SPMS_Technical_Spec_for_Claude_Code.pdf` — المواصفة الفنية ودليل البناء
  (القرارات المعمارية، نموذج البيانات، منطق الوراثة والحساب، الأمن، خريطة البناء).
- تقرير فحص النظام (27 صفحة) — ملاحظات وتوصيات من فحص الإصدار السابق، تُراعى عند
  تصميم واجهات APEX في المراحل P4 وما بعدها (خاصة: عرض اسم المؤشر لا الكود REQ-012،
  توحيد نقطة إدخال النشاط REQ-005، التوزيع اليدوي للمستهدفات REQ-030).
- ملفات الخطة الاستراتيجية والتقارير الربعية (Excel) — بيانات فعلية للأبعاد
  والأهداف والمؤشرات وقوالب التقارير المعتمدة، تُستخدم كمرجع لملء بيانات الخطة
  وكقالب لتصميم شاشات التقارير في P7.
